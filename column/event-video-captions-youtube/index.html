행사 영상 자막은 유튜브 자동 자막을 그대로 두지 말고, 사람 이름 · 기관명을 검수하거나 축사 원고로 다시 만드는 것이 기본입니다. YouTube 고객센터는 자동 자막을 사용할 수 있으면 자막이 동영상에 자동으로 게시된다고 안내하는데, 행사 영상은 고유명사가 많아 자동 자막이 틀리기 쉽습니다. 축사 · 강연 · 시상 영상을 의뢰처 채널에 올리기 전에 자막을 어떻게 만들고 누가 확인할지 정리했습니다. YouTube 고객센터라고 밝힌 내용 말고는 모두 현장에서 흔히 쓰는 일반 요령입니다.

핵심만 먼저
  • 자막을 사용하면 청각장애인이나 난청이 있는 시청자, 다른 언어를 사용하는 시청자 등 더 다양한 시청자에게 동영상을 공유할 수 있습니다(YouTube 고객센터).
  • 자동 자막은 사용할 수 있는 경우 동영상에 자동으로 게시되고, 동영상의 기본 언어로만 제공됩니다(YouTube 고객센터).
  • 자막을 넣는 방법은 파일 업로드 · 자동 동기화 · 직접 입력 세 가지이며, 자동 동기화는 스크립트를 붙여넣으면 타이밍이 자동으로 설정됩니다(YouTube 고객센터).
  • 한 시간이 넘거나 음질이 좋지 않은 동영상에는 스크립트 작성이 적합하지 않다고 안내하므로, 긴 행사 영상은 나눠 올리거나 다른 방법을 씁니다(YouTube 고객센터 · 일반 요령).
  • 자막 속 이름 · 직함 · 기관명은 공개 전에 의뢰처가 한 번 더 확인하게 합니다(일반 요령).

1행사 영상에 자막을 왜 따로 챙겨야 하나요?

한 시간이보다 긴 동영상에는 스크립트 작성이 적합하지 않음(YouTube 고객센터)
3가지자막 추가 방법 — 파일 업로드 · 자동 동기화 · 직접 입력(YouTube 고객센터)

연말에는 기념식 축사, 포럼 강연, 시상식 수상 소감을 영상으로 남겨 기관 · 단체 채널에 올려 달라는 요청이 많습니다. 편집자는 화면과 소리에 집중하다 보니 자막은 유튜브가 알아서 붙여 주겠거니 하고 넘기기 쉽습니다.

자막을 사용하면 청각장애인이나 난청이 있는 시청자, 다른 언어를 사용하는 시청자 등 더욱 다양한 시청자층에 동영상을 공유할 수 있습니다.— YouTube 고객센터 「자막 추가」

여기에 더해 요즘은 지하철이나 사무실에서 소리를 끄고 영상을 보는 사람도 많습니다. 축사처럼 말이 전부인 영상은 자막이 없으면 첫 몇 초 만에 넘겨지기 쉽습니다(일반 요령). 현장에서 문자통역 · 수어통역을 어떻게 준비하는지는 용인 무장애 행사 준비 글에, 온라인 행사의 실시간 자막은 수원 웨비나 운영 점검 글에 따로 정리했습니다. 이 글은 행사가 끝난 뒤 녹화 영상을 올릴 때만 다룹니다.

2유튜브 자동 자막을 그대로 두면 무엇이 틀리나요?

YouTube 고객센터는 "자동 자막을 사용할 수 있는 경우에는 자막이 동영상에 자동으로 게시됩니다."라고 안내합니다. 따로 손대지 않아도 자막이 보이니 편하지만, 행사 영상은 자동 자막이 약한 말로 가득합니다.

축사 영상에서 내빈 이름이나 기관명이 틀린 자막은 단순 오타보다 크게 받아들여집니다. 자동 자막을 켜 둔 채 공개하기 전에, 최소한 이름 · 직함 · 기관명 · 숫자만큼은 사람이 확인합니다(일반 요령).

또 YouTube 고객센터는 "자동 자막은 동영상의 기본 언어로만 제공됩니다."라고 안내합니다. 동영상 언어 설정이 실제 말하는 언어와 다르면 자동 자막이 제대로 나오지 않을 수 있으니, 업로드할 때 언어 설정부터 봅니다(일반 요령).

3축사 원고가 있으면 자막을 더 쉽게 만들 수 있나요?

있습니다. YouTube 고객센터는 자막을 넣는 방법으로 아래 세 가지를 안내합니다. 행사 영상에서는 축사 · 강연 원고를 받아 두는 것이 가장 큰 차이를 만듭니다.

다만 연사는 원고를 그대로 읽지 않는 일이 많습니다. 인사말을 덧붙이거나 문단을 건너뛰면 원고와 실제 말이 어긋나니, 원고를 붙여넣기 전에 영상을 들으며 실제 말한 대로 고친 뒤 넣습니다(일반 요령). 원고는 행사 전에 의전 담당자에게 미리 받아 두면 편집 단계에서 다시 찾을 일이 없습니다.

4두세 시간짜리 행사 영상은 어떻게 하나요?

포럼 · 학술행사처럼 녹화가 길면 자동 동기화에 기대기 어렵습니다. YouTube 고객센터는 "길이가 한 시간이 넘거나 음질이 좋지 않은 동영상에는 스크립트 작성이 적합하지 않습니다."라고 안내합니다.

  1. 나눠 올리기 — 개회 · 축사, 기조강연, 발표별로 영상을 잘라 각각 한 시간 안쪽으로 만듭니다.
  2. 소리 따로 받기 — 촬영 카메라 마이크 소리 대신 음향 콘솔에서 받은 소리를 써서 음질을 확보합니다.
  3. 방법 고르기 — 한 시간이 넘는 원본을 그대로 올려야 하면 편집 프로그램에서 만든 자막 파일을 업로드하는 방법을 검토합니다.
  4. 핵심부터 — 일정이 빠듯하면 축사 · 기조강연처럼 많이 볼 영상부터 자막을 검수합니다.
음질은 현장에서 정해집니다. 녹화할 행사라면 음향 감독에게 '녹음용 소리를 따로 달라'고 미리 말해 두는 것이 자막 작업 시간을 가장 많이 줄입니다(일반 요령). 생중계를 함께 하는 경우의 준비는 행사 유튜브 생중계 준비 글을 봅니다.

5의뢰처와 무엇을 정해 두나요?

영상은 편집자가 만들지만 자막 속 이름과 표현의 책임은 결국 의뢰처 채널이 집니다. 작업 지시 단계에서 아래를 정해 두면 공개 뒤 수정 요청이 줄어듭니다(일반 요령).

6공개 전 자막 점검은 어떤 순서로 하나요?

  1. 행사 전 — 축사 · 강연 원고와 내빈 명단을 받아 둡니다.
  2. 업로드 — 비공개로 올리고 동영상 언어 설정이 맞는지 봅니다.
  3. 자막 만들기 — 원고가 있으면 실제 말한 대로 고쳐 자동 동기화로, 없으면 자동 자막을 고치거나 직접 입력합니다.
  4. 검수 — 이름 · 직함 · 기관명 · 숫자를 명단 · 원고와 대조하고, 박수 구간의 엉뚱한 자막을 지웁니다.
  5. 소리 끄고 보기 — 소리를 끈 채 처음부터 끝까지 넘겨 보며 자막만으로 내용이 이해되는지 봅니다.
  6. 의뢰처 확인 — 담당자에게 비공개 링크를 보내 이름 표기를 확인받고 공개합니다.

행사 결과보고서에 영상 링크를 함께 넣을 때는 결과보고서 사진 정리 글도 참고합니다. 연말 행사 일감과 전국 축제 소식은 이벤트 코리아 홈에 모아 두었습니다.

자주 묻는 질문

유튜브 자동 자막이 붙으면 따로 자막을 안 만들어도 되나요?

YouTube 고객센터는 자동 자막을 사용할 수 있으면 자막이 동영상에 자동으로 게시된다고 안내합니다. 다만 행사 영상은 이름 · 기관명 · 숫자가 많아 틀리기 쉬우니, 최소한 고유명사는 사람이 검수하는 것이 일반 요령입니다.

축사 원고를 붙여넣으면 타이밍도 맞춰지나요?

YouTube 고객센터는 동영상 자막의 스크립트를 입력하거나 붙여넣을 수 있고, 이 옵션을 사용하면 자막 타이밍이 자동으로 설정된다고 안내합니다. 연사가 원고와 다르게 말한 부분은 먼저 고쳐서 넣습니다.

두 시간짜리 포럼 영상에도 원고 붙여넣기를 쓸 수 있나요?

YouTube 고객센터는 길이가 한 시간이 넘거나 음질이 좋지 않은 동영상에는 스크립트 작성이 적합하지 않다고 안내합니다. 발표별로 나눠 올리거나 자막 파일 업로드를 검토하는 것이 일반 요령입니다.

영어 강연도 자동 자막이 나오나요?

YouTube 고객센터는 자동 자막이 동영상의 기본 언어로만 제공된다고 안내합니다. 업로드할 때 동영상 언어를 실제 강연 언어로 맞춰 두는지 확인합니다.
