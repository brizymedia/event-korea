3회선이 끊기면 어떻게 이어 가나요?

연회장 · 강당 와이파이는 참석자 휴대전화가 함께 붙어 행사 시작 무렵 가장 느려집니다. 송출은 행사장 공용 와이파이에 얹지 않고, 송출 전용 유선을 따로 받는 것이 기본입니다(일반 요령).

  1. 주 회선 — 행사장 관리실에 송출 전용 유선 포트를 요청하고, 조작석까지 케이블 길이를 미리 잽니다.
  2. 예비 회선 — 다른 통신사 휴대전화 데이터나 휴대용 라우터를 하나 더 준비해 조작석에 꽂아만 둡니다.
  3. 끊김 판단 — 시청 화면이 일정 시간 멈추면 예비 회선으로 넘기는 기준 시간을 송출 담당과 미리 정합니다.
  4. 현장 녹화 — 송출과 별도로 인코더나 카메라에서 원본을 녹화해, 송출이 끊긴 구간도 나중에 영상으로 남깁니다.
  5. 안내 문구 — '잠시 송출이 끊겼습니다, 곧 이어집니다' 대기 화면을 한 장 만들어 둡니다.
채널당 활성 스트림은 10개, 스트림 키당 3개로 제한됩니다(YouTube 고객센터). 여러 행사를 한 채널 · 한 키로 겹쳐 돌릴 계획이면 키를 나누고, 끝난 테스트 송출은 꼭 종료합니다.

4송년회 · 기념식 · 시상식 화면은 어떻게 짜나요?

현장 관객은 무대를 보지만, 유튜브 시청자는 화면만 봅니다. 그래서 식순이 바뀔 때마다 지금 무엇을 하는지 화면에 보여 줘야 이탈이 줄어듭니다(일반 요령).

  • 대기 화면: 시작 전 행사명 · 시작 시각을 띄우고 배경음악은 권리가 확인된 것만 씁니다. 음악 권리는 김해 행사 음악 저작권 글을 봅니다.
  • 식순 자막: 개회 · 기념사 · 시상 · 축하 공연처럼 순서 이름을 화면 아래에 띄웁니다.
  • 시상식 하단 자막: 수상자 이름 · 상 이름을 미리 파일로 만들고, 호명 순서표와 번호를 맞춥니다. 호명 순서는 안산 시상식 진행 글을 참고합니다.
  • 쉬는 시간 화면: 식사 · 휴식 동안에는 객석을 비추지 말고 안내 화면으로 바꿉니다.
  • 종료 화면: 마치는 인사 뒤 '시청해 주셔서 감사합니다' 화면을 잠시 띄우고 송출을 끝냅니다.

카메라 자리는 무대 정면 한 대를 기본으로, 시상식이면 수상자가 올라오는 계단 쪽을 비추는 한 대를 더 둡니다. 조작석은 음향 조작석 옆에 붙여야 큐 사인을 같이 받기 쉽습니다(일반 요령).

5출연자와 관객에게 촬영을 어떻게 알리나요?

생중계는 나중에 편집으로 빼 줄 수가 없습니다. 그래서 수상자 · 공연 출연자에게는 출연 확정 때 '유튜브로 생중계되고 다시보기가 남는다'를 알리고, 관객에게는 입구 안내판과 사회자 멘트로 알립니다. 촬영을 원하지 않는 사람이 앉을 촬영 제외석과 카메라가 비추지 않을 구역도 미리 정합니다(일반 요령).

카메라 촬영 고지와 거부 의사 처리의 법 기준은 춘천 행사 생중계 관객 촬영 고지 글에 정리했습니다. 포토부스 · 즉석 인화처럼 얼굴이 크게 남는 촬영은 포토부스 운영 글, 끝난 뒤 사진 · 영상을 고를 때 얼굴 · 아이 사진 배려는 결과보고서 사진 정리 글을 함께 봅니다.

  • 사회자 멘트: 개회 전 '오늘 행사는 유튜브로 생중계됩니다. 촬영을 원하지 않는 분은 안내 스탭에게 말씀해 주세요'를 한 번 넣습니다.
  • 객석 컷: 박수 장면은 뒷모습 · 넓은 화면 위주로 잡고, 식사 중인 얼굴을 가까이 비추지 않습니다.
  • 아이 출연: 가족 송년회에 아이 무대가 있으면 보호자에게 생중계 여부를 먼저 알립니다.

6리허설 송출 테스트는 어떤 순서로 하나요?

리허설 날에는 무대 리허설과 별도로 송출 리허설을 잡습니다. 본방송과 같은 장비 · 같은 회선 · 같은 채널로, 공개 범위만 비공개나 일부 공개로 바꿔 실제로 내보내 봅니다(일반 요령).

  1. 장비 연결 — 카메라 · 음향 콘솔 출력 · 인코더를 실제 자리에 놓고 연결합니다.
  2. 테스트 송출 — 비공개로 10분 이상 내보내고, 다른 휴대전화로 시청 화면을 열어 지연 시간을 잽니다.
  3. 소리 확인 — 사회자 마이크 · 무선마이크 · 배경음악이 시청 화면에서 고르게 들리는지 이어폰으로 듣습니다.
  4. 화면 전환 — 대기 화면 → 식순 자막 → 시상식 하단 자막 → 쉬는 시간 화면을 큐시트 순서대로 한 번씩 넘겨 봅니다.
  5. 회선 전환 — 주 회선을 일부러 뽑고 예비 회선으로 넘어가는 데 걸리는 시간을 확인합니다.
  6. 종료 — 테스트 송출을 끝내고, 테스트 영상이 공개로 남지 않았는지 채널에서 확인합니다.

기술 리허설과 큐 리허설을 하루에 어떻게 나누는지는 행사 리허설 진행표 글에 있습니다. 연말 행사 일감 · 전국 축제 소식은 이벤트 코리아 홈에 모아 두었습니다.

자주 묻는 질문

행사 유튜브 생중계를 처음 하는 채널은 언제 준비해야 하나요?

YouTube 고객센터는 휴대기기 첫 라이브 스트림을 시작하기까지 24시간을 기다려야 할 수도 있다고 안내합니다. 채널 인증과 라이브 기능 사용 설정은 행사 일주일 전쯤 끝내 두는 것이 일반 요령입니다.

구독자가 적은 채널도 휴대전화로 라이브를 할 수 있나요?

YouTube 고객센터 기준으로 휴대기기에서 라이브 스트림을 하려면 구독자가 50명 이상이어야 합니다. 구독자가 적다면 노트북과 인코더로 송출하는 방법을 검토합니다.

라이브 스트리밍 제한을 받은 채널은 어떻게 되나요?

YouTube 고객센터는 라이브 스트리밍을 하려면 지난 90일간 라이브 스트리밍 제한을 받은 적이 없어야 한다고 안내합니다. 발주처 채널에 제한 이력이 있으면 다른 채널로 송출할지 미리 정합니다.

생중계 리허설은 공개로 해도 되나요?
