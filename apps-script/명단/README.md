# 이벤트인 명단 서버 — 설치

명함을 만들거나 앱을 받는 사람의 **이름·전화·직군**을 시트에 모으고, 동의한 사람에게 **새 행사 입찰을 문자로** 보냅니다.
문자 업체 설정이 없으면 「시험 모드」로 돌아 실제로 보내지 않습니다(요금 걱정 없음).

## 1. 서버 만들기 (5분)

1. https://script.new → 프로젝트 이름 **「이벤트 코리아 명단」**
2. `이벤트코리아-명단서버.gs` 내용을 통째로 붙여넣기 (기존 내용 지우고)
3. 위 함수 목록에서 **「점검」** 고르고 ▶ 실행 → 권한 창이 뜨면 승인
   - 로그에 「명단 시트 : https://docs.google.com/…」 가 나오면 시트가 만들어진 것 (내 드라이브 → 이벤트 코리아 폴더)
4. **배포 → 새 배포 → 웹 앱** · 실행 사용자 **나** · 액세스 **모든 사용자** → 배포
5. 나온 `/exec` 주소를 저에게 주세요 → 앱 내려받기 페이지와 명함 페이지에 박습니다

## 2. 문자 (하고 싶을 때, 나중에 해도 됨)

1. **알리고**(https://smartsms.aligo.in) 가입 → 발신번호 등록 (1533-7295 또는 휴대폰 · 사업자 서류 인증) → 문자 충전 (단문 약 15원)
2. 알리고 「API 연동」에서 **API 키** 받기 (서버 IP 등록은 「등록하지 않음/전체 허용」으로)
3. 앱스 스크립트 → 프로젝트 설정 → **스크립트 속성**에 넣기
   | 속성 | 값 |
   |---|---|
   | `ALIGO_KEY` | 알리고 API 키 |
   | `ALIGO_ID` | 알리고 아이디 |
   | `ALIGO_SENDER` | 등록한 발신번호 (숫자만, 예 15337295) |
   | `TEST_TEL` | 시험 문자 받을 내 번호 (예 01012345678) |
4. 함수 **「시험문자」** 실행 → 내 폰에 한 통 옵니다 (요금 1건)
5. 함수 **「트리거걸기」** 실행 → **매주 월요일 09시** 자동 발송 (매일로 바꾸려면 코드 한 줄, 저에게)

문구 예: `[이벤트코리아] 행사 입찰 새로 7건, 마감임박 3건 / event-korea.co.kr/#live` — 단문 90바이트 안에서 자동 조절.

## 시트 구조 (자동 생성)

**명단** — 등록시각 · 이름 · 전화 · 직군 · 지역 · 출처(명함/앱/포털) · 문자동의(Y/N) · 최근활동 · 메모 · 마지막문자
**문자 발송 기록** — 시각 · 새 입찰 · 마감 임박 · 대상 · 보낸 수 · 결과 · 문구

- 같은 번호가 다시 오면 새 줄을 안 만들고 갱신합니다 (출처가 「명함 · 앱」처럼 쌓임)
- **수신 거부**는 시트에서 그 사람의 문자동의를 `N` 으로 바꾸면 됩니다 (전화·문자로 요청 오면)
- 입찰 정보만 보내는 정보성 문자라 (광고) 표시 대상이 아닙니다. 홍보 문구를 섭지 마세요 — 섭으면 광고 규정(표시 · 080 수신거부)이 붙습니다

## 비용 감

| 명단 | 주 1회 단문 | 월 |
|---|---|---|
| 100명 | 100건 × 4 | 약 6,000원 |
| 300명 | 300건 × 4 | 약 18,000원 |

앱을 깐 사람은 **앱 알림으로 매일 무료**로 받으니, 문자는 앱 안 깐 사람용 보조 수단입니다.
